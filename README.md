# آرکان گلد — پروژه Astro (نسخه‌ی به‌روزشده)

پیاده‌سازی صفحات اصلی سایت آرکان گلد با Astro + Tailwind CSS، راست‌به‌چپ (RTL)، فارسی،
با اتصال زنده به API قیمت طلا و هویت بصری جدید.

## اجرای پروژه

```bash
npm install
npm run dev       # اجرای محلی روی http://localhost:4321
npm run build     # خروجی نهایی برای دیپلوی، در پوشه dist
npm run preview   # پیش‌نمایش خروجی build شده
```

## هویت بصری جدید

| نقش | کد رنگ | توکن Tailwind |
|---|---|---|
| رنگ اصلی (زرشکی تیره) | `#330509` | `brand` (و `maroon` به‌عنوان alias قدیمی) |
| رنگ فرعی (طلایی) | `#c5a059` | `gold` |

فونت‌ها یک پله درشت‌تر از قبل تنظیم شده‌اند (`tailwind.config.mjs` → `theme.extend.fontSize`).

## اتصال قیمت لحظه‌ای طلا (مهم‌ترین بخش فنی)

تمام قیمت‌های نمایش داده‌شده در سایت (هیرو، ماشین‌حساب خرید/فروش، نوار هدر، نمودار،
صفحه قیمت) از **یک منبع واحد** تغذیه می‌شوند:

```
src/lib/goldPrice.ts       ← سرویس مرکزی: fetch، نرمال‌سازی، polling هر ۳۰ ثانیه
src/lib/priceBinding.ts    ← اتصال خودکار المان‌های data-price-bind به سرویس بالا
```

### منبع فعلی
```
GET https://api.talasea.ir/api/market/getGoldPrice
```

### نکته‌ی مهم که باید تایید شود
مقدار `price` در پاسخ API (مثلاً `"23587"`) واحدش با «تومان به ازای هر گرم طلای ۱۸ عیار»
که در کل سایت نمایش داده می‌شود فرق دارد. در `src/lib/goldPrice.ts` یک ضریب موقت
به نام `RAW_PRICE_MULTIPLIER` گذاشته شده تا وقتی واحد دقیق از طرف تیم/API تایید شود،
فقط همین یک عدد اصلاح شود:

```ts
// src/lib/goldPrice.ts
const RAW_PRICE_MULTIPLIER = 1000; // ⚠️ باید با واحد واقعی API تایید/اصلاح شود
```

### استفاده در یک کامپوننت جدید
هر جای سایت که بخواهید قیمت زنده نشان دهید، کافی است:

```html
<span data-price-bind="pricePerGram" data-price-format="toman">در حال دریافت...</span>
<span data-price-bind="changePercent">--</span>
<span data-price-bind="fetchedAt">--</span>
```

و در یک تگ `<script>` همان فایل:

```js
import '../lib/priceBinding'; // یا مسیر نسبی صحیح بسته به عمق پوشه
```

با این کار المان به‌صورت خودکار در بارگذاری اول و سپس هر ۳۰ ثانیه بروزرسانی می‌شود
(بدون نیاز به نوشتن کد fetch تکراری).

برای منطق سفارشی‌تر (مثل ماشین‌حساب که باید ضرب در گرم انجام دهد)، مستقیماً از
`subscribeGoldPrice()` استفاده کنید — نمونه‌ی کامل در `src/components/sections/Hero.astro`
و `GoldCalculator.astro` موجود است.

### نمودار قیمت (Chart.js)
نمودار فعلاً فقط تب «زنده» را با داده‌ی واقعی (بافر تاریخچه‌ی محلی که هر ۳۰ ثانیه
یک نقطه اضافه می‌کند) رسم می‌کند. تب‌های «روزانه/هفتگی/ماهانه» placeholder هستند.

**نقطه‌ی اتصال آینده:** تابع `fetchRangeData()` در
`src/components/sections/PriceChart.astro` — وقتی API بازه‌ی زمانی واقعی آماده شد،
فقط همین تابع باید به `fetch` واقعی وصل شود؛ بقیه‌ی کد (رندر نمودار، آمار کمترین/بیشترین)
بدون تغییر کار می‌کند.

### فیلدهای دیگر پاسخ API که استفاده می‌شوند
- `disableBuy` / `disableSell` + پیام‌های مربوطه → غیرفعال کردن دکمه‌ی خرید/فروش در
  `GoldCalculator.astro` به‌صورت خودکار
- `fee` → نمایش کارمزد در `PriceChart.astro`
- `change24h` → نمایش درصد تغییر (سبز/قرمز) در همه‌جا

## آیکون‌های سفارشی

به‌جای آیکون‌های ژنریک، یک کتابخانه‌ی SVG اختصاصی ساخته شده:

```
src/components/Icon.astro
```

استفاده:
```astro
<Icon name="gold-bar" class="h-6 w-6" />
```

آیکون‌های موجود: `gold-bar`, `coin-stack`, `necklace`, `ring`, `gift-card`, `shield`,
`seal`, `bank`, `lock`, `vault`, `scale`, `clock`, `headset`, `percent`, `invoice`,
`location`, `trend-up`, `sparkle`, `smartphone`, `chevron`, `gold-drop`, `wallet`,
`document`, `handshake`, `question`.

برای افزودن آیکون جدید، یک ورودی به آبجکت `paths` در `Icon.astro` اضافه کنید.

## هدر و فوتر

- **هدر**: پس‌زمینه سفید، زیرمنوی «خدمات» با آیکون مرتبط، نوار قیمت زنده (مارکی)،
  منوی تمام‌صفحه در موبایل، پاپ‌آپ QR دانلود اپلیکیشن هنگام هاور روی «دانلود اپلیکیشن».
- **فوتر**: تک‌رنگ `#330509`، سه ستون (برند/شبکه‌های اجتماعی، دسترسی سریع، پشتیبانی و تماس)،
  کاملاً ریسپانسیو (روی موبایل ستون‌ها زیر هم قرار می‌گیرند).

## پالت رنگی — تک‌رنگ برند

طبق آخرین تصمیم، پالت رنگی سایت به یک رنگ اصلی محدود شده:

- **`#330509` (برند):** تمام پس‌زمینه‌های تیره (هدر، فوتر، پنل‌ها، دکمه‌ها)، متن‌های کلیدی،
  بوردرها و گرادیان‌های تزئینی — همه از همین یک تن رنگی (با روشن/تیره‌ی جزئی برای عمق بصری)
  ساخته می‌شوند.
- **`#c5a059` (طلایی):** فقط برای جزئیات بسیار کوچک باقی مانده — مثل خط جداکننده‌ی نازک
  (`gold-divider`)، یک نقطه‌ی تزئینی کوچک، یا هاور یک لینک متنی. هیچ‌جا به‌عنوان
  پس‌زمینه‌ی سطح بزرگ، گرادیان اصلی دکمه یا کارت استفاده نمی‌شود.
- روی پس‌زمینه‌های تیره، تمام متن‌ها سفید/روشن هستند (نه طلایی) تا خوانایی حداکثر باشد.

اگر در آینده خواستید این قانون را تغییر دهید، محل تمرکز اصلی `tailwind.config.mjs`
(بخش‌های `backgroundImage` و `colors.brand`) و `src/styles/global.css` (کلاس‌های `.btn-primary`،
`.btn-light`) است.

## نوار قیمت زنده — نمایش در موبایل

نوار قیمت لحظه‌ای زیر هدر اکنون در **همه‌ی اندازه‌های صفحه از جمله موبایل** نمایش داده
می‌شود (قبلاً فقط در دسکتاپ بود). در منوی تمام‌صفحه‌ی موبایل نیز یک نسخه‌ی کوچک از قیمت
زنده بالای فهرست لینک‌ها تکرار شده تا همیشه در دید کاربر باشد. این بخش‌ها در
`src/components/Header.astro` قرار دارند و مثل همیشه از `src/lib/priceBinding.ts` تغذیه
می‌شوند.


1. **تایید واحد قیمت API** — `RAW_PRICE_MULTIPLIER` در `src/lib/goldPrice.ts`
2. **CORS در production** — قیمت طلا از `api.talasea.ir` مستقیم از مرورگر (client-side) قابل
   فراخوانی نیست چون آن سرور هدر CORS ندارد. برای هاست نهایی باید یک پراکسی (Cloudflare
   Worker، یا API route روی `api.arkan.gold` با هدر `Access-Control-Allow-Origin`) جلوی
   `GOLD_PRICE_API_URL` در `src/lib/goldPrice.ts` قرار گیرد. جزئیات کامل در تاریخچه‌ی گفتگوی
   پروژه ثبت شده است.
3. **فونت**: فایل `Vazirmatn-Variable.woff2` را در `public/fonts/` قرار دهید
4. **تصاویر محصولات**: تصاویر واقعی محصولات را در `public/images/products/` جایگزین placeholder کنید
5. **API بازه‌ی زمانی نمودار**: وقتی آماده شد، `fetchRangeData()` در `PriceChart.astro`
   را وصل کنید
6. **فرم تماس و ورود**: اتصال به backend واقعی

## صفحه‌ی قوانین و مقررات (`/rules`)

متن کامل قوانین (۱۷ بخش) اکنون به‌صورت ساختاریافته در `src/data/rules.ts` نگهداری می‌شود.
صفحه‌ی `src/pages/rules.astro` این داده را می‌خواند و یک فهرست موضوعات چسبان (sticky)
در کنار محتوا نمایش می‌دهد؛ کلیک روی هر آیتم فهرست با اسکرول نرم به همان بخش می‌رود و
هنگام اسکرول صفحه، آیتم فعال فهرست به‌صورت خودکار هایلایت می‌شود (`IntersectionObserver`).

برای ویرایش متن قوانین در آینده، فقط کافی است آرایه‌ی `rulesSections` در
`src/data/rules.ts` را ویرایش کنید؛ افزودن یک بخش جدید به آرایه به‌طور خودکار هم در فهرست
موضوعات و هم در محتوای صفحه ظاهر می‌شود.
