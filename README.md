# آرکان گلد — پروژه Astro

پیاده‌سازی صفحات اصلی سایت آرکان گلد با Astro + Tailwind CSS، راست‌به‌چپ (RTL)، فارسی، و
آماده برای سئو و اتصال ابزار آنالیز.

## اجرای پروژه

```bash
npm install
npm run dev       # اجرای محلی روی http://localhost:4321
npm run build     # خروجی نهایی برای دیپلوی، در پوشه dist
npm run preview   # پیش‌نمایش خروجی build شده
```

> نکته: چون شبکه‌ی محیط توسعه فعلی محدود بود، `npm install` روی این پروژه اجرا نشده؛
> اولین اجرا را حتماً خودتان با اتصال اینترنت عادی انجام دهید.

## ساختار پروژه

```
src/
  layouts/BaseLayout.astro     # اسکلت HTML، متا‌تگ‌ها، JSON-LD سازمانی، هدر/فوتر
  components/                  # هدر، فوتر، سئو، آنالیز
  components/sections/         # بخش‌های قابل‌استفاده مجدد (Hero, Features, Steps, ...)
  data/                        # منبع واحد داده (FAQ، محصولات) — یک‌بار تعریف، همه‌جا استفاده
  pages/                       # هر فایل = یک مسیر واقعی در سایت
public/
  robots.txt, favicon.svg, fonts/, images/   # فایل‌های استاتیک
```

### صفحات ساخته‌شده

| مسیر | توضیح |
|---|---|
| `/` | صفحه اصلی — دقیقاً مطابق نمونه‌ای که فرستادید |
| `/shop` | فروشگاه با فیلتر دسته‌بندی |
| `/shop/[slug]` | صفحه اختصاصی هر محصول |
| `/buy-gold` | خرید طلای آب‌شده + ماشین‌حساب قیمت |
| `/sell-gold` | فروش طلا + ماشین‌حساب قیمت |
| `/about` | درباره ما |
| `/contact` | تماس با ما + فرم |
| `/faq` | سوالات متداول کامل |
| `/services`, `/price`, `/login`, `/rules`, `/cooperation` | صفحات سبک/جایگزین برای تکمیل ناوبری — محتوای واقعی باید جایگزین شود |

لینک «مجله آرکان گلد» در هدر و بخش «مطالب مجله» در صفحه اصلی مستقیماً به
**`https://arkan.gold/mag`** (وردپرس) وصل است. بخش مطالب مجله در صفحه اصلی از طریق
REST API وردپرس (`/mag/wp-json/wp/v2/posts`) آخرین ۳ پست را در لحظه build/render می‌خواند؛
اگر بلاگ در دسترس نباشد، آن بخش بی‌صدا مخفی می‌شود.

## کارهای باقی‌مانده قبل از انتشار

1. **فونت**: فایل `Vazirmatn-Variable.woff2` را در `public/fonts/` قرار دهید (از
   [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) قابل دانلود است).
2. **تصاویر**: تصاویر واقعی هیرو و محصولات را در `public/images/` جایگزین placeholder ها کنید.
3. **قیمت لحظه‌ای**: عدد ثابت در `GoldCalculator.astro` و `price.astro` را به API واقعی
   قیمت طلا وصل کنید.
4. **فرم تماس**: در `contact.astro`، fetch را به یک endpoint واقعی (API route یا سرویس
   ایمیل) وصل کنید.
5. **لوگو واقعی**: `logo.png` را برای og:image/JSON-LD در `public/` قرار دهید.

## سئو (SEO)

- هر صفحه از کامپوننت `<Seo />` استفاده می‌کند: تیتر، توضیحات، canonical، Open Graph،
  Twitter Card.
- `astro.config.mjs` آدرس دامنه (`SITE_URL`) و `@astrojs/sitemap` را تنظیم کرده؛ بعد از
  build، فایل `sitemap-index.xml` خودکار ساخته می‌شود (صفحات `/mag` که خارج از این پروژه
  و در وردپرس هستند از sitemap این پروژه حذف شده‌اند تا تداخل ایجاد نشود).
- `robots.txt` در `public/` آماده است و به sitemap اشاره می‌کند.
- داده‌های ساخت‌یافته (JSON-LD): `Organization` در همه صفحات، `FAQPage` در صفحه اصلی و
  `/faq`، `Product`/`ItemList` در فروشگاه.
- تصاویر باید `alt` معنادار فارسی داشته باشند (نمونه در `Hero.astro`).
- ساختار عنوان‌ها (h1 یک‌بار در هر صفحه، سلسله‌مراتب h2/h3) رعایت شده است.

### پیشنهاد گام بعدی برای سئوی وردپرس (بلاگ)

چون `arkan.gold/mag` روی وردپرس است، بهتر است:
- پلاگین سئو (مثل Rank Math یا Yoast) روی آن نصب و sitemap مجزای `mag/sitemap_index.xml`
  را در Google Search Console به‌صورت جدا از این پروژه ثبت کنید.
- در `robots.txt` این پروژه هیچ محدودیتی برای `/mag` نگذاشته‌ایم؛ اگر وردپرس روی همان
  دامنه در مسیر `/mag` نصب است، robots.txt و sitemap خودِ وردپرس اولویت دارد و باید با
  این فایل هماهنگ/یکپارچه شود (یا در ادغام نهایی، هر دو robots.txt را یکی کنید).

## آنالیز (Analytics)

فایل `src/components/Analytics.astro` آماده اتصال است و در `BaseLayout` روی همه صفحات
لود می‌شود. کافیست فایل `.env` را از روی `.env.example` بسازید:

```bash
cp .env.example .env
```

و مقدار مربوطه را پر کنید:

```
PUBLIC_GA4_ID=G-XXXXXXXXXX      # برای Google Analytics 4
PUBLIC_YEKTANET_ID=xxxxxxxx      # برای یکتانت آنالیتیکس (باید کد رسمی نصب جایگزین شود)
```

اگر ابزار دیگری (مثل متریکا، هاتجار و ...) نیاز شد، در همین فایل یک بلوک مشابه اضافه
کنید — نیازی به تغییر جای دیگر پروژه نیست.
