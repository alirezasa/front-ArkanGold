# تصاویر نمادهای فوتر

تصویر هر نماد را با یکی از این نام‌ها در همین پوشه بگذارید (پسوند png، jpg، webp یا svg):

| فایل | نماد |
|---|---|
| `enamad.png` | نماد اعتماد الکترونیکی (فقط اگر کد رسمی اینماد در `PUBLIC_ENAMAD_ID`/`PUBLIC_ENAMAD_CODE` تنظیم نشده باشد) |
| `virtual-business-union.png` | اتحادیه کسب‌وکارهای مجازی |
| `gold-union.png` | اتحادیه طلا و جواهر |
| `fintech.png` | انجمن فین‌تک |
| `central-bank.png` | بانک مرکزی |

بهتر است تصویر با پس‌زمینه‌ی شفاف یا سفید و حدود ۲۰۰×۲۰۰ پیکسل باشد. نام و لینک هر نماد در `src/data/trustSeals.ts` است.
